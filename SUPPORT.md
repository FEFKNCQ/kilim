# Getting help

| I want to… | Go here |
|---|---|
| Ask a question or share an idea | [GitHub Discussions](https://github.com/yusufyilmazfr/kilim/discussions) |
| Report a bug | [New bug report](https://github.com/yusufyilmazfr/kilim/issues/new?template=bug_report.yml) |
| Request a feature or a new rug pattern | [New feature request](https://github.com/yusufyilmazfr/kilim/issues/new?template=feature_request.yml) |
| Fix or add a translation | [Translation issue](https://github.com/yusufyilmazfr/kilim/issues/new?template=translation.yml) or a pull request (see [CONTRIBUTING](CONTRIBUTING.md#translations)) |
| Report a security problem | [SECURITY.md](SECURITY.md) – please do **not** use public issues |
| Support the project | [GitHub Sponsors](https://github.com/sponsors/yusufyilmazfr) |

Before opening an issue, please check the [Troubleshooting section](README.md#troubleshooting) of the README and search existing issues.

Kilim is maintained in spare time. We answer as quickly as we can, but there is no guaranteed response time.
