## Taybetmendî

- **Fîzîka qumaşê ya rastîn** – xalîçeyê bigire, bikişîne, tewand û bavêje.
- **Îkonên sermaseyê vedişêre** – li cihê îkonan bilindahî çêdibin û dema îkonê dikişînî wî dişopînin.
- **Moda dîtinê** – ⌥ Option (dikare were guhertin) bigire: xalîçe zelal dibe û tu dikarî li îkonan bitikînî.
- **Pêçan** – du caran bitikîne, xalîçe dipêçe; dîsa du caran bitikîne, vedibe.
- **16 nexş** – Farisî, Tirkî, Kurdî, Misirî, Berber, Kazak, Çînî, Ayasofya, İznik, Selçûqî… û **xalîçeya ji wêneyê xwe**.
- **Ronahiya roj û şevê** – reng û sî li gorî demjimêrê diguherin.
- Dengê qumaşê û ketinê (bi kodê tên çêkirin), piştgiriya gelek ekranan, 21 ziman.
- Sivik û nepenî: bê ağ, bê analîtîk.

## Sazkirin

```sh
curl -fsSL https://raw.githubusercontent.com/yusufyilmazfr/kilim/main/Scripts/install.sh | bash
```

1. `Kilim-<guherto>.zip` ji rûpela [Releases](https://github.com/yusufyilmazfr/kilim/releases/latest) dakişîne.
2. Zip veke û **Kilim.app** bikişîne peldanka `Applications`.
3. Cara yekem **rast-klîk → Veke** bike (sepan notarîzekirî nîne) an jî: `xattr -dr com.apple.quarantine /Applications/Kilim.app`
4. Kilim di darika menuyê de dijî (îkona Dock tune). Heke macOS destûra kontrolkirina **Finder** bixwaze, **OK** bike – tenê ji bo xwendina cihê îkonan tê bikaranîn.

Ji bo ji çavkaniyê çêkirinê macOS 13+ û Xcode Command Line Tools bes in:

```sh
git clone https://github.com/yusufyilmazfr/kilim.git
cd kilim
make run
```

## Bikaranîn

| Çalakî | Encam |
|---|---|
| Xalîçeyê bikişîne | Bigire, hilgire an tewand |
| Du caran bitikîne | Bipêçe / veke |
| ⌥ Option bigire | Dîtin: xalîçe zelal dibe, tikandin diçe îkonan |
| Wêneyek bavêje ser îkona darika menuyê | Xalîçeya xwe biweşîne |
| Îkona darika menuyê | Nexş, ronahî, deng, ziman, destpêkirina bi têketinê, bişkoka dîtinê |

## Nepenî û destûr

- Bê gihîştina înternetê, bê telemetrî, bê hesab.
- Destûra **Automation → Finder** tenê ji bo xwendina cihê îkonan e; bêyî wê xalîçe dîsa dixebite, tenê bê bilindahî.
- Wêneya xalîçeya te tenê li ser makîneya te tê tomarkirin (`~/Library/Application Support/Kilim/`).
